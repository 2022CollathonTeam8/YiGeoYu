# 📱 이거유? - 대전지역 분실물 찾기 앱  

### Collathon 2022 - 8조 최종 프로젝트  

## 프로젝트 개요  

**이거유?** 는 대전 지역의 분실물과 습득물을 빠르고 쉽게 연결하는 어플입니다. 습득자의 불편을 최소화하고 분실자가 소중한 물건을 되찾을 수 있도록 소통을 돕는 기능을 제공합니다.  

### 🧑‍🤝‍🧑 팀 구성  
- **팀장**: 이세준 (컴퓨터공학과, 2학년) - 개발, 일정 조율, 문서 작업  
- **팀원**: 변지영 (전기공학과, 4학년) - 기획, 디자인, 시장 조사  
- **팀원**: 신나영 (메카트로닉스공학과, 1학년) - 설문조사, 문서 작업, 디자인 보조  

---

## 개발 환경 및 도구  
- **개발 환경**: Visual Studio Code, Xcode, Android Emulator  
- **프레임워크**: React Native (Expo CLI)  
- **CI/CD**: GitHub  
- **디자인 툴**: Figma, Adobe Illustrator  
- **문서 작업**: Notion  

---

## 주요 기능  
1. **물건 습득자 기능**  
   - 사진 업로드 및 습득 장소, 물건 상태 입력  
   - 질문을 통해 분실자와 소통  

2. **물건 분실자 기능**  
   - 분실물 검색 및 습득자와 채팅  
   - 위치와 동선을 입력해 습득자와 소통 가능  

3. **알림 및 사용자 경험 강화**  
   - 키워드 알림: 관련 분실물 게시 시 알림 제공  
   - 습득자 순위 및 감사 인사 기능 제공  
   - ‘온정 부피’ 시스템으로 지역 공동체 신뢰 도모  

---

## 프로젝트 차별성  
- **정확한 물건 매칭**: 제한된 정보 공개 후 습득자-분실자 간 문답을 통해 매칭  
- **감사 인사 강화**: 여러 번 하트를 누를 수 있는 기능 제공  
- **간소화된 사용 경험**: 글 작성 과정을 최소화해 참여 장려
